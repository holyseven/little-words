## 孩子与家长的使用流程

1. 家长长按首页齿轮并验证，在「学校课程 · 一年级上册」选择老师当前单元。
2. 首页「继续今天的课」进入该单元，也可接着上次的位置学习。6 个单元均可直接选。
3. 单元分为「听课文」「看动画」「单词跟读」。按文件名页码选择课文；动画显示原片封面与时长；单词按原始单元音轨整段跟读。
4. 播放器提供播放/暂停、重听、上一段/下一段、拖动与视频全屏。默认 1×，家长可选 0.85× / 0.7×。孩子主动点播，结束后停留，后台或离页暂停。
5. U2 / U6 可进入现有数字/颜色拓展游戏，并提示练习范围可能比课本更广。其余主题仍可从「单词乐园」进入。

中文开关、外观、奖励与家长限时保持生效；课本媒体速度单独设置。到达每日上限立即暂停，直达播放器地址也不能绕过休息页。

## 学习记录、每日任务和奖励

- 记录每份材料最近位置、真实播放覆盖、完成状态及当天覆盖。观看材料不自动把单词记为掌握。
- 覆盖至少 90% 且播放结束，首次完成该文件 +1 星。拖动跳过的部分不计入，重复听同一区间不增加覆盖，重复完成不再次发首次奖励。
- 默认每日任务取学校当前单元的课文、动画、单词音频各一段，优先未完成材料。任务要求当天覆盖达到 90% 并播完；三项完成 +10 星每天一次，在最后一段结束后结算。
- 家长也可选单词乐园任务。当天已生成的任务固定不变，单元或来源调整从次日任务生效；首页显示的当前单元立即更新。
- JSON 备份包含课程记录与新设置，旧备份仍可导入；严格检查材料 ID、位置、区间和日期。备份不含媒体，导入保留本机 PIN。

## 离线使用

生产版核心预缓存约 2.55 MiB，课程另有约 53 MiB。家长页提供「下载当前单元」「下载整册」「暂停下载」以及每单元/整册删除。完成数由实际缓存核对；显式下载逐文件校验字节数与 SHA-256。取消或断网后可重试，正确副本无需重复下载。

课程采用原生媒体元素，长音轨无需全部解码常驻内存。独立 Cache Storage 保存完整文件，Vite PWA 已有的 Workbox `rangeRequests` 配置支持离线 206 响应，保证视频拖动和续播准确；媒体不进入核心 4 MiB 单文件上限的自动预缓存。删除下载保留学习记录。

**使用 HTTPS 生产构建版**，从主屏幕启动并确认核心 Service Worker 就绪，再在家长页下载整册，等待「已下载 61 / 61 份」，之后才进行飞行模式测试。核心缓存就绪不等于课程下载完成。Mac localhost 可以测试离线，iPad 访问局域网 HTTP 和开发热更新版仅作功能预览。
